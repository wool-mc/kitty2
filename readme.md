## 🖼️ Описание приложения

- Приложение отображает галерею котиков с возможностью добавления их в избранное:

- Список котиков подгружается с API и отображается в виде карточек.

- Можно добавлять и удалять котиков из избранного.

- Избранные котики хранятся с уникальными ID, а состояние синхронизируется с сервером.

- LikeButton показывает, добавлен ли котик в избранное.

- Компоненты KittyCard и KittyCardList переиспользуемы и поддерживают адаптивный дизайн.

- Приложение полностью TypeScript, с типами Kitty и FavoriteKitty.

- Поддерживается асинхронная загрузка данных и обработка ошибок.
