Kitty Gallery

Небольшой проект на React + TypeScript + Vite для отображения котиков из API с возможностью добавлять их в избранное.

Возможности:
  Отображение списка котиков (Kitty и FavorKitty)

  Добавление и удаление котиков из избранного

  Быстрый поиск в избранном с помощью Set

  Типизированные API-запросы через Axios и TypeScript

  SVG-иконки как React-компоненты (через SVGR)

  Полная типизация TypeScript

  ESLint + Prettier для единообразного кода

  Vite для быстрой разработки и HMR
